# 《奈奈与薰的SM日记》专题站视觉与交互重设计

**日期：** 2026-11-08  
**状态：** 待审阅  
**范围：** 现有 Vue 3 + Vite 静态站的页面结构、视觉、阅读交互重构

## Intent

把站点从「十二块图墙往下堆」改成一部漫画的专题展示：首页介绍作品，三个篇各自独立浏览，封面 / 彩图 / 双页图继续单独展示，阅读改为横向无缝横带。

受众是站点作者自己（及偶尔分享给熟人）。成功标准：打开站能一眼认出这是《奈奈与薰》专题；三篇好找；特别图集不被章节淹没；阅读像翻画册，默认从右到左。

## Goals

- 专题首页：作品介绍 + 三个篇入口（带数量）
- 篇页：上方特别展示入口（封面 / 彩图 / 双页），下方章节列表
- 图集页：单独展示某一类特别图
- 阅读页：横向横带、页与页无缝相贴、默认 RTL、可切 LTR 并记住
- 清爽浅色视觉（白底 + 樱粉点缀），图片是主角
- 修掉现有错误标题、硬编码详情元数据、把整串 `pages` 塞进 query、重复 key

## Non-goals

- 不做多部作品的通用漫画站
- 不做账号、评论、搜索、后端、数据库
- 不改动 `public/image` 里的图片文件本身
- 不引入新的 UI 组件库（继续用现有 Vue 生态）

## Anti-goals

- 做成通用 manga reader 模板，首页看不出是哪一部作品
- 把封面 / 彩图 / 双页并进章节列表、失去单独展示
- 竖向长滚阅读作为唯一方式（已否决）

## Constraints

- 技术栈：Vue 3 + Vue Router + Pinia + Vite + TypeScript + `v-viewer`（可保留作辅助，阅读主路径用横带）
- 数据：继续用 `src/data/book{1,2,3}-*.json` 与 `public/image/`
- 三篇映射：本篇 = book1，夏日篇 = book2，高校篇 = book3
- 数量以 JSON 条目为准（本篇 160 话 / 封面 18 / 彩图 18 / 双页 41；夏日篇 45 / 5 / 5 / 51；高校篇 31 / 5 / 5 / 21）

## Approaches considered

| 做法 | 说明 | 取舍 |
|------|------|------|
| **A. 在现有项目上重构（采用）** | 保留图片与 JSON，重做路由与页面，修数据传递与标题 | 改动集中、风险可控 |
| B. 推倒新建项目 | 同一套图，新脚手架 | 收益不大，迁移成本高 |
| C. 只改 CSS | 不动结构与阅读交互 | 达不到「更好用」 |

**选择：** A。用户已确认专题定位、首页结构、篇内 C 布局、横带阅读、浅色风格。

## Design

### 信息架构与路由

| 路径 | 页面 | 内容 |
|------|------|------|
| `/` | 专题首页 | 作品 hero + 三个篇卡片（含各类数量） |
| `/part/:part` | 篇页 | `part` ∈ `main` \| `summer` \| `school`。上方三块特别展示入口，下方章节网格 |
| `/part/:part/gallery/:kind` | 图集页 | `kind` ∈ `covers` \| `pictures` \| `dual`。网格展示该类全部条目 |
| `/read` | 阅读页 | query：`part`、`source`（`chapter` \| `covers` \| `pictures` \| `dual`）、`id`（话数 `num` 或条目索引）。**不把 pages 数组塞进 URL** |

「从本篇开始读」→ `/part/main`。

### 专题首页

- Hero：封面图、书名、作者（甘詰留太）、出版社（白泉社）、标签、一段作品简介、主 CTA「从本篇开始读」
- 作品级元数据只出现在这里（及可选的关于区），**不再在每一话详情里硬编码重复**
- 三张篇卡片：篇名、代表封面、数字（章节 / 封面 / 彩图 / 双页）

### 篇页（布局 C）

```
[ ← 返回专题 ]  本篇

特别展示
[ 封面图 18 ]  [ 彩图 18 ]  [ 双页图 41 ]

章节（160 话）
[第1话 妄想] [第2话 …] …
```

- 点特别展示入口 → 对应图集页
- 点章节卡片 → 阅读页（该话）

### 图集页

- 标题带篇名与类型、数量
- 封面 / 彩图：单图卡片网格
- 双页：左右并排卡片（保留现有 dual 展示语义）
- 点条目 → 阅读页，`source` 对应该类型
- **封面 / 彩图点进阅读时只放被点中的那一张展示图**，忽略条目里附带的卷级 `pages`。同图集内可用上一张 / 下一张在展示图之间切换，仍然不展开整卷

### 阅读页（横带）

- 横向排列全部页图，**页与页无缝相贴**（无 gap / 无白边分隔）
- 默认阅读方向：**从右到左**；UI 可切换为从左到右；选择写入 `localStorage`
- 交互：拖动、水平滚轮/触控板、键盘 ←→；松手后 snap
- 顶栏：返回、当前标题（话名或图集名）、页码指示、方向切换。双页阅读时额外显示停靠方式切换；章节与单图不显示该开关
- 双页图 source：横带中相邻两页按对开关系排列（与 dual JSON 的 left/right 一致）
- **停靠方式**：双页阅读默认 **按一对开停**（一次挪左右两页，页码按对计）；可切换为 **按单页停**（一次挪一张）。选择写入 `localStorage`。章节与单图图集始终按单页停
- 章节缺 `pages` 时：尝试按该卷目录补全页序列；无法补全则只显示封面图并在顶栏提示「暂无完整页」

### 视觉

- 清爽浅色：近白背景、樱粉强调色、浅阴影卡片
- 字体：非默认 Inter 栈；标题可用有表现力的中日文友好字体（实现时选定具体 webfont）
- 图片始终是视觉主角；装饰不压过封面与彩图
- 响应式：首页三卡片小屏纵向叠放；阅读页横带全宽，顶栏可收起

### 数据与代码整理

- 统一 `part` → book 数据的映射模块（chapters / covers / pictures / dual）
- 修正现有错误标题（夏日篇彩图误标封面、高校篇章节误标夏日篇等）
- 章节列表 key：不用单独 `leftImageUrl`（本篇 101/102 共用封面）；改用 `part + num` 或稳定 id
- 清理 Vue 模板残留文件与无用欢迎组件（实现计划中列为可删清单，不阻塞主功能）
- 详情页硬编码 ISBN / 页数 / 简介 / 日期：删除；作品信息回到首页

### Error / edge cases

- 无效 `part` / `kind` / `id` → 回专题首页或篇页，并短暂提示
- 图片 404：占位与跳过，不打断横带滚动
- 极窄屏：横带仍横向；顶栏简化

### Testing（轻量）

- 路由：三篇、三类图集、一话阅读可进可退
- 阅读方向、双页停靠方式切换后刷新仍保持
- 列表 key 无控制台重复警告
- 现有 Playwright / Vitest：补关键路径冒烟；不要求像素级视觉回归

## What’s left to the builder

- 具体 CSS 变量数值、字体最终选型（方向已定：白底 + 樱粉）
- 夏日篇 / 高校篇缺 `pages` 时，卷内切段的边界容错（封面页码对不齐时如何回退，见 Builder calls）

## Decisions after builder check

实现者检查后由用户拍板（2026-11-08）：

1. 封面 / 彩图点进阅读页时，横带只用那一张展示图，不用条目上的 `pages` 整卷。
2. 双页图默认按一对开 snap，并提供切换为按单页 snap。

## Builder calls

- 「从本篇开始读」落到篇页 `/part/main`，不直接进第 1 话。
- 字体与具体色值在实现时选定，保持白底 + 樱粉、图片为主角。
- 夏日篇 / 高校篇章节缺 `pages` 时：按该话封面所在卷目录、用相邻话封面页码切段补全；切不出则只显示封面并提示。
- `v-viewer` 保留为双击放大，主阅读路径是横带。
- 封面 / 彩图阅读以被点中的那一张为主；同图集提供上一张 / 下一张，只在展示图之间移动。

## Approval

用户在对话中已确认：专题定位、首页结构、篇内 C、横带 RTL 可切换、视觉 A、封面只用展示图、双页默认为对开可切单页。  
书面 spec 审阅通过后进入 `writing-plans`。
